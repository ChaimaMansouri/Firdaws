# 🌙 Firdaws Website

**Firdaws** is a modern Islamic platform designed to provide access to the **Holy Quran**, **live Islamic channels**, and **accurate prayer times** — all in one elegant and easy-to-use website.  
Built with **HTML, CSS, and JavaScript**, and powered by several **public APIs**.

---

## ✨ Main Features

### 📖 1. Quran Reciters & Narrations
- Fetches a list of Quran reciters dynamically using an **API**.  
- Allows users to select a reciter and listen to recitations.  
- Displays the narration (*Riwaya*) for each reciter.  

---

### 📺 2. Live Islamic Channels
- 📡 **Live stream of the Holy Quran Channel (Makkah).**  
- 🌴 **Live stream of the Sunnah Channel (Madinah).**

---

### 🕰️ 3. Prayer Times by Country and City
- Retrieves daily **prayer times** based on the selected **country and city** using the **API**.  
- Automatically updates the times daily.  
- Provides accurate local times for Fajr, Dhuhr, Asr, Maghrib, and Isha.

---
